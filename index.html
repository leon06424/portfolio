    - 홈페이지 리뉴얼 6건: 기존 사이트 구조 개선 및 웹 접근성을 고려한 시맨틱 마크업 및 UI 구현

    - 랜딩페이지 제작 20건: 반응형 레이아웃, 스크롤 애니메이션, 상담 신청 폼 UI 제작

    - 100여 개 업체 홈페이지 유지보수: 페이지 수정, 콘텐츠 업데이트 및 UI 개선. PHP 기반 기존 웹사이트 유지보수. 워드프레스(WordPress), 카페24(Cafe24), 아임웹(Imweb) 등 다양한 플랫폼 기반 사이트 운영 지원

    - JavaScript를 활용한 메뉴, 탭 등 UI 인터랙션 및 스크롤 애니메이션 구현

    - 디자인 시안을 기반으로 한 웹 페이지 마크업 및 레이아웃 구현

  • - 웹 퍼블리싱 전담 역량: 신규 제작 및 리뉴얼 프로젝트의 퍼블리싱 전반을 주도적으로 수행

    - 멀티 플랫폼 대응: 워드프레스, 카페24, 아임웹 등 다양한 플랫폼 환경에서의 유지보수 및 커스터마이징

    - 반응형 및 인터랙션 구현: 다양한 화면 크기에 대응하는 레이아웃과 JavaScript 기반 인터랙션 구현

    - 웹사이트 운영 및 개선: 다수 업체의 유지보수 경험을 바탕으로 다양한 사이트 구조에 대한 이해와 실무 대응 역량 보유

  • 3년간 웹 에이전시에서 근무하며 신규 홈페이지 제작, 리뉴얼, 랜딩페이지 제작 및 유지보수 업무를 수행해 왔습니다.

    신규 홈페이지 11건, 리뉴얼 6건, 랜딩페이지 20건의 퍼블리싱을 담당했으며, 100여 개 업체의 홈페이지 유지보수를 통해 다양한 웹사이트 구조와 플랫폼에 대한 실무 경험을 쌓았습니다.

    HTML/CSS 기반의 웹 페이지를 중심으로 반응형 레이아웃, JavaScript 인터랙션 및 스크롤 애니메이션, 웹 접근성을 고려한 시맨틱 마크업 및 UI 구현해 왔습니다. 또한 워드프레스, 카페24, 아임웹 등 다양한 플랫폼 환경에서 페이지 수정과 UI 개선 업무를 수행하며 각 환경에 맞춰 유연하게 대응하는 역량을 키웠습니다.

    프로젝트의 요구사항과 디자인 시안을 정확하게 구현하는 것을 중요하게 생각하며, 신규 제작부터 리뉴얼과 유지보수까지 폭넓게 경험한 실무 역량을 바탕으로 완성도 높은 웹 페이지를 구현하고 팀의 업무에 기여하겠습니다.
